# 智能日程管理工具

一个由抖音视频《只用豆包Agent编程，能做出什么？》启发的单文件 HTML 应用，无需构建工具、双击即可使用。

## 功能
- 周/日/月/今日 四种视图
- 课程/考试/作业/活动/自定义 五类日程
- 倒计时、学期进度、待办事项
- 明暗主题、拖拽调课、冲突并排
- JSON 导入导出
- AI 助手：支持接入任意大模型 API（豆包/OpenAI/DeepSeek/Kimi/智谱/通义/Ollama 等）

## 使用
直接打开 `index.html` 即可。
